THE EVIDENCE, SIDE BY SIDE

Recall = the proportion of actual attacks caught.

Clean, poisoned and defended results are shown together here. All bars use a 0–100% axis. Means are over seeds 42–46; standard deviations are not displayed. The story explains saved results, rather than running the Python models live.

New to cybersecurity? Start here.

A network intrusion detector checks whether traffic is benign (normal) or an attack. A supervised model learns using examples with labels that provide the training answers. Label flipping changes those answers without changing the traffic features.

DDoS means distributed denial of service: an attack that overwhelms a service with traffic. Accuracy covers all test predictions; recall focuses on actual attacks. A high accuracy can hide damage to one attack category.

Which experiments does this show?

Both models were trained on a balanced CICIoT2023 subset: 182,000 records and 46 features, split into 145,600 training records and 36,400 unchanged test records. The split stayed fixed while experiment seeds varied from 42 to 46.

Random poisoning selected from all Attack training samples. Targeted poisoning selected only DDoS training samples. The rates 5%, 10% and 20% apply to each strategy's eligible training population. Only Attack → Benign labels changed, starting from a fresh clean copy each time.

Equal-flip comparisons and ablation experiments were also part of the project. This showcase displays the primary rate-based comparisons.

How does the defence clean the data?

The first stage checks whether nearby examples disagree with a sample's supplied label. The second filters class-wise outliers. Suspicious samples are removed before model training; they are never relabelled. Original labels and poisoning records are used only for subsequent evaluation.

Are the animations live model predictions?

No. This is an explanatory GUI built around saved experiment results. The moving traffic is not live network traffic or a replay of recorded predictions. The number of packets and cards is symbolic and does not encode the measured poisoning rate, recall or removal count.

During label flipping and cleaning, no newly trained model's score is shown. Each subsequent model was trained separately and evaluated on the same unchanged test set. The miss rate is 100% minus recall; for targeted DDoS runs this is the reported ASR, not a baseline-adjusted causal measure.
